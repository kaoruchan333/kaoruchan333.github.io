1. いまのユータさん

薫さんから伺っているユータさんは、もう、自分で走っている人です。

Claude Codeを自分で動かしています。Threads、インスタグラム、ストーリーズ、note。自分で戦略を立てて、ストレスなく、自分らしく発信しています。noteからの収入は、月に平均でおよそ5万円（薫さんから伺った数字です。期間や内訳は、これから一緒に確かめます）。パソコンには、AntigravityもClaude Codeも入っています。

ここに、新しく教えることは、ありません。

2. これからの問い

次の問いは、「もっと書けるようになるには」ではありません。

「何を、どう届けたら、応援と収益が、いまより伸びるか」 です。

まず、いまの5万円が、どこから生まれているのかを確かめる。そこから、伸ばせそうな点を、ひとつずつ試していく。その先を、どうしたいか。いまの形を育てたいのか、本業にしていきたいのか。それは、最初に、ユータさんに確かめます。そのための、最初の話をします。

3. すでに持っている宝物

ゼロからではありません。

サッカーの現場で見てきた「一瞬」の言葉。親御さんに読まれてきた記事。5月時点の記録では、何本も売れた記事と、リピーターの親御さんがいました（いまの状況は、最初のAI会議で確かめます）。いくつもの発信の場所。

そして、5月時点の記録では、売上を天川のサッカーの活動につなげる構想がありました。いまの使い道と、その伝え方は、ユータさんに確かめます。

4. 詰まりそうな場所（仮説です）

ここは、ユータさんに確かめてもらう「仮説」です。

記事は、1本ずつ並んでいる。まとめて見せる棚が、まだ足りないかもしれない。価格は、いまの形が一番いいのか。発信の入口から、noteの購入ページまで、道がつながっているか。もう一度買ってくれる人に、次の一歩を用意できているか。

どれが本当の詰まりかは、ユータさんの数字を見て、決めます。

5. 2つのAIに、役割を分ける

ユータさんの手元には、AIが2つあります。

Claude Code は、ユータさんが移した記事や記録を読んで、事実を整理する「記録係の参謀」です（どこまで移せているかは、最初に確かめます）。

Antigravity は、初めて読む親御さんの目、ほかの人の目で見て、「それ、本当に伝わる？」と別の角度から言ってくれる「もうひとりの参謀」です。

一人のAIに聞くより、考えの違う二人に聞く。ここが大事です。

6. 毎週30分の「AI会議」

流れは、5つだけです。

ひとつめ。この1週間の数字と投稿を、ユータさんが並べる。

ふたつめ。Claude Codeが、事実を整理して、案を出す。

みっつめ。Antigravityが、別の目で、反対や代わりの案を言う。

よっつめ。二人の案から、次の実験を、多くて3つに絞る。

いつつめ。ユータさんが、1つだけ選ぶ。 決めるのは、いつも、ユータさんです。

この会議は、AIに答えを決めてもらう場所ではありません。ユータさん自身が、マーケティングを学び、自分で判断できるようになる場所です。

7. noteの「棚」を作る（試す案）

まず、新しい記事を書く前に、いままでの有料記事を、全部ひとつの表にします。タイトル、テーマ、いつ出したか、どれだけ売れたか、どこから来た人か。

すると、見えてきます。いまも売れる記事。入口が切れている記事。同じ悩みの親御さんに向けて、まとめられる記事。

そのまとまりを、「マガジン」という棚にする。順番をつけて、読みやすく見せる。単品で買った人が、次に手に取れる棚をつくる。価格は、最初は、変えません。まず、並べ方と入口だけを試します。

8. ひとつの「現場の一瞬」を、4つの場所で役割分担

同じ文章を、4つの場所に貼るのではありません。

Threadsは、現場の一言と問いかけ。反応を見て、仮説を集める。

インスタグラムは、保存したくなる図や、親御さんが見返せる判断の基準。

ストーリーズは、つくっている途中と、期間を決めた案内。

noteは、背景、具体的な方法、深い理解。

そして、全部、同じ着地点（その週に伝えたいひとつの記事かマガジン）につなげます。

9. 天川への循環を、まっすぐ伝える

5月時点の記録では、売上を天川のサッカー教室や、将来のチームづくりにつなげる構想がありました。いまの使い道と、どこまで読者に見せたいかは、ユータさんに確かめます。そのうえで、もし伝えるなら、次の形がおすすめです。

だから、売り込みの言葉にしません。ユータさんが決めた短い一文を、記事の最後に置く。何に使えたのかを、見せられる範囲で、報告する。子どもたちが特定される情報は、使わない。「買えば、救える」とは言わない。静かに、事実で伝えます。

10. 毎週見る数字

見るのは、少しだけです。

どの場所から、noteに来たか。どの記事が、買われたか。初めての人か、もう一度の人か。商品ごとの売上。かかった時間。

数字は、勝ち負けのためではなく、「次に、何を試すか」を決めるために見ます。

11. 守ること

ユータさんの言葉を、AIが勝手に作りません。公開するのは、いつも、ユータさんです。外に出す、お金に関わる、何かを消す、というときは、「ユータさんが「いいよ」と言うまで待つ」というルールをAIに渡して、毎回、確かめます。子どもたちが誰か分かる書き方は、しません。結果は、約束しません。

12. 最初の一歩（2週間）

ひとつめ。いまの有料記事を、棚卸しの表にする。AIに手伝ってもらって大丈夫。

ふたつめ。30分、AI会議をひらく。ユータさんのAIに貼るだけで始まる「会議の最初の言葉」を、一緒に渡します。

みっつめ。一番売れているテーマを、ひとつだけ選んで、2週間、並べ方と入口だけを変えて試す。値段や、ほかのものは、変えない。

2週間後に、数字を見て、続ける、変える、やめる、を、ユータさんが決める。

1. ユータさんの現在地と、確かな才能

すでにClaude Codeを自分で走らせ、Threads、Instagram、ストーリーズ、noteで戦略的に発信しています。noteからの収益は月平均およそ5万円。

分析する力、戦略を立てる力、子どもたちや保護者に向き合う情熱は、すでに本物です。ゼロから教えることは何もない。すでにある強みを何倍にも広げるためのステップです。

2. 一人で走る限界と「AIの伝言係」の罠

AIを使おうとすればするほど、指示書（プロンプト）作りに追われ、AIごとの出力を別のAIへ運ぶ「伝言係」になってしまう罠があります。

記事を書き、発信を整え、サッカー現場に立ち、事業を考える……すべてを一人で抱え込むと、一番大切な「戦略」を練る時間が削られてしまいます。

3. 薫ちゃんがAIチームと実際にやっていること

薫ちゃんはAIに上手なプロンプトを書いていません。伝えるのは4つだけです：

  1. 構想：どんな形にしていきたいか
  2. 優先順位：いま、どれを先にやりたいか
  3. こだわり・違和感：ここだけは外せない／なんか引っかかる
  4. 最後の判断：並んだ選択肢から「これで行く」と決める

残りの調査・比較・下書き・実装・検証は、AIチームが裏で直接往復させています。

4. ユータさんの手元に置く「2つの参謀AI」

Claude Code（記録・事実整理の参謀）：note記事の棚卸し、過去の数字の整理、事実に基づいたロジカルな提案を行う。

Antigravity（初めて読む人の目・別の視点の参謀）：保護者の目線で「本当に伝わるか？」を検証し、別の切り口や反対意見を提示する。

同じ意見を出すAIではなく、異なる個性を持つ2つのAIが裏で議論します。

5. ユータを伝言係にしない連携の仕組み

ユータさんが「こんな企画をやりたい」「ここがなんか引っかかる」と話す。Claude Codeが事実を整理し、裏でAntigravityに「どう思う？」と投げる。

Antigravityが別の角度から反論や改善案を出し、練り上げられた「選べる3案」がユータさんの机に戻ってくる。ユータさんは社長として、最後に1つを選ぶだけです。

6. 1つが止まっても、別のAIが引き継ぐ

AIには利用上限があり、途中で止まることがあります。その時、進んだふりをせず「ここまで完了、次はこれ」と記録に残して止まる。

別のAIがその記録を読んで続きから再開する（耐障害性の引き継ぎ）。一人のAIに依存しない、頑牢なチーム運営基盤です。

7. 使うほど積み上がる「無形の資産」

毎回ゼロからやり直さない。記事の棚卸しデータ、読者の反応、成功パターン、失敗した理由がすべて蓄積されます。

ユータさんがサッカーの現場で子どもたちと向き合っている間も、整えた仕組みが価値を生み出し続けます。

8. 天川のサッカー教室と、描く未来へ

noteの収益化はゴールではありません。得られた収益と時間を、天川でのサッカー教室や、子どもたちの才能を解き放つ未来へ循環させていく。

ユータさんのビジョンを実現するために、この相棒AIチームが存在します。

9. 決めるのは、いつもユータさんです

外部への公開、送信、お金、削除は、ユータさんが「よし」と言うまでAIは一切触れません。

AIはユータさんの手足を何倍にも増やす相棒。経営者として舵を握るのは、ずっとユータさんです。
