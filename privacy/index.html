プライバシーポリシー

制定日：2026年11月7日

このページは、前田薫が自分の活動のために使っているGoogle連携のしくみ（アプリ名「kaoru-forms」）で、情報をどう扱うかを説明するものです。

1. 何のために使うか

このしくみは、前田薫本人のGoogleアカウントだけで使っています。目的は次の3つです。

  • イベントやコーチングの申込みフォームを作り、届いた申込みを確認すること
  • 申込みがあったときに、本人あての通知メールや朝のお知らせメールを送ること
  • 本人のGoogleドライブ・Gmailにある資料やメールを整理すること

2. 扱う情報

フォームに申込みいただいた方のお名前・連絡先・ご記入内容と、前田薫本人のGoogleドライブ・Gmailの内容です。

3. 外に出さないこと

  • いただいた情報は、申込みへのご連絡と活動の運営のためだけに使います。
  • 第三者に売ったり、渡したり、広告に使ったりすることはありません。
  • Google APIから受け取った情報の扱いは、Googleの「API Services User Data Policy」（Limited Use の要件を含む）に従います。

4. 保管と削除

情報は前田薫のGoogleアカウントの中に保管します。ご自身の情報の確認や削除をご希望の場合は、下のホームページからご連絡ください。
